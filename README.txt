PHONEPARTS — FRONTEND NAMUNA

Fayllar:
- index.html : mijozlar sayti tuzilishi
- styles.css : mijozlar sayti dizayni
- app.js     : mijozlar sayti demo funksiyalari
- admin.html : admin paneli tuzilishi
- admin.css  : admin paneli dizayni
- admin.js   : admin paneli demo funksiyalari

Ishga tushirish:
1. Barcha fayllarni bir xil papkada saqlang.
2. index.html faylini brauzerda oching.
3. Admin panelini ko‘rish uchun saytdagi “Admin” havolasini bosing yoki admin.html ni oching.

MUHIM:
Bu hozircha brauzerda ishlaydigan frontend prototip. Login, mijoz ma'lumotlari, haqiqiy buyurtmalar, buyurtma raqamini parallel buyurtmalarda noyob berish, ombor/to‘lovlar, audit tarixi, ruxsatlar, zaxira nusxalar va fayllarni serverda saqlash uchun backend hamda ma'lumotlar bazasi kerak. Hozirgi mahsulotlar va hisobotlar demo ma'lumotlar bo‘lib, sahifa yangilanganda o‘zgarishlar saqlanmaydi.

Ekranlar ichki kodi:
Bir xil ichki kod bitta mahsulotni anglatishi kerak. Bir nechta telefon markasi/modeli bilan moslikni bitta mahsulot yozuviga bog‘lash backend sxemasida bajariladi. Hozirgi demo takroriy ichki kodni qo‘shishda ogohlantiradi, ammo mavjud mahsulotga moslik qo‘shishni alohida backend amali sifatida to‘liq amalga oshirmaydi.
